# Pulse — интерфейс управления рассылками

Адаптивный русскоязычный фронтенд для системы email-рассылок с ориентиром на 92 000 сообщений. HTML, CSS и JavaScript без runtime-зависимостей и этапа сборки.

## Запуск

Требуется Node.js 18 или новее.

```sh
cd pulse-mail
npm run dev
```

Откройте http://localhost:5173. Для другого порта используйте `PORT=3000 npm run dev`.

Проверка синтаксиса: `npm run check`.

## Возможности

- Обзор кампаний, показатели и графики с переключением периода.
- Поиск, фильтры и пагинация кампаний.
- Создание, редактирование и копирование черновиков.
- Три шаблона писем.
- Импорт CSV: проверка email, удаление дублей, лимит 92 000 контактов и 5 МБ на файл.
- Поиск по аудитории и экспорт CSV с защитой от формул в табличных редакторах.
- Настройки пространства и отправителя, сохранение в localStorage.
- Адаптивное меню, диалоги с клавиатурным управлением, уведомления.

## Статус интеграции

Это frontend-прототип. Начальная статистика, кампании и аудитория на 92 000 сообщений являются демонстрационными. Пауза и продолжение изменяют только локальный демо-статус. Реальных отправок и фоновой обработки нет. Период графика переключает демонстрационные наборы данных; сводные показатели относятся к примеру за 14–20 ноября 2026.

Пользовательские кампании, настройки и импортированные контакты сохраняются в браузере этого устройства. Возможность сохранения зависит от квоты localStorage. Реальные секреты и ключи провайдера не следует хранить во фронтенде.

Для производственной системы нужны backend API, общая база данных, аутентификация, очередь с повторами и ограничением скорости, почтовый провайдер, вебхуки доставок, управление согласиями и отписками. Вместимость демо-интерфейса не является проверкой пропускной способности сервера.

## Структура

- `dist/index.html` — оболочка приложения.
- `dist/styles.css` — оформление и адаптивные состояния.
- `dist/app.js` — представления, локальное состояние и взаимодействия.
- `server.mjs` — локальный HTTP-сервер.
- `.openai/hosting.json` — конфигурация статического размещения Sites.

Шрифт Manrope загружается из Google Fonts; при недоступности сети используется системный шрифт.
