# Uved.kz — массовая WhatsApp-рассылка через GREEN-API

Сервис для рассылки по базе до ~100 000 контактов: админка, очередь отправки с прогревом номеров, приём статусов и ответов, стоп-лист. Номера WhatsApp подключаются по QR-коду прямо из админки.

Один процесс Node.js (API, админка, вебхук, воркер очереди), данные в SQLite. Redis и внешняя БД не нужны.

## Запуск

### Docker (рекомендуется)

```sh
cp .env.example .env      # заполните значения, см. ниже
docker compose up -d --build
```

Админка откроется на `http://127.0.0.1:3000`. База SQLite и загруженные файлы лежат в томе `pulse-data` (`/data` в контейнере) и переживают пересборку.

Обновление: `git pull && docker compose up -d --build`.
Резервная копия: `docker compose exec pulse node -e "require('better-sqlite3')('/data/app.db').backup('/data/backup.db').then(()=>console.log('ok'))"` и скопируйте `/data/backup.db`.

### Без Docker

Нужен Node.js 20+.

```sh
npm ci
cp .env.example .env
npm run dev               # node --env-file=.env src/server.js
```

Данные по умолчанию — в папке `./data` (меняется переменной `DATA_DIR`).

### Переменные `.env`

| Переменная | Назначение |
| --- | --- |
| `ADMIN_LOGIN` | Логин для входа в админку. По умолчанию `admin`. Регистр не важен. |
| `ADMIN_PASSWORD` | Пароль входа в админку. Обязателен. |
| `GREEN_PARTNER_TOKEN` | Партнёрский токен GREEN-API. С ним кнопка «Подключить номер» сама создаёт подключение — клиенту остаётся только QR-код. Без него клиент занимает подключения, которые заранее добавил администратор. |
| `MAX_NUMBERS` | Максимум номеров при автосоздании. По умолчанию `10`. |
| `PUBLIC_URL` | Внешний HTTPS-адрес сервиса, например `https://wa.example.com`. Без него не работают вебхуки и отправка файлов. |
| `WEBHOOK_SECRET` | Секретная часть адреса вебхука. `openssl rand -hex 24` |
| `SESSION_SECRET` | Ключ подписи cookie. `openssl rand -hex 32` |
| `TZ_NAME` | Часовой пояс для дневных лимитов и окна отправки. По умолчанию `Asia/Almaty`. |
| `PORT` | Порт сервиса. По умолчанию `3000`. |
| `MIN_DELAY_SEC` | Минимальная пауза между сообщениями одного номера. По умолчанию `5`. |

## HTTPS через reverse proxy

GREEN-API присылает статусы доставки и входящие сообщения на `PUBLIC_URL/webhook/<WEBHOOK_SECRET>`, а файлы для рассылки скачивает по ссылке `PUBLIC_URL/media/<файл>`. Поэтому сервис должен быть доступен из интернета по HTTPS. Сам сервис слушает только `127.0.0.1`, наружу его отдаёт прокси.

**Caddy** (сертификат выпускается автоматически):

```
wa.example.com {
    reverse_proxy 127.0.0.1:3000
    request_body {
        max_size 100MB
    }
}
```

**Nginx** (сертификат — через certbot):

```nginx
server {
    listen 443 ssl;
    server_name wa.example.com;
    ssl_certificate     /etc/letsencrypt/live/wa.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/wa.example.com/privkey.pem;

    client_max_body_size 100m;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 120s;
    }
}
```

После смены `PUBLIC_URL` или `WEBHOOK_SECRET` нажмите у каждого номера «Переустановить webhook».

Публично доступны только `/webhook/…` и `/media/…`. Всё остальное закрыто паролем.

## Порядок работы

1. **Номера.** В личном кабинете GREEN-API создайте инстанс. В админке: «Номера» → «Добавить номер» → `idInstance`, `apiTokenInstance`, `apiUrl` из карточки инстанса. Сервис проверит доступ, пропишет вебхук и покажет QR-код — отсканируйте его в WhatsApp («Связанные устройства»). Отправьте себе тестовое сообщение.
2. **База.** «База» → «Импортировать файл» (XLSX или CSV в UTF-8 / Windows-1251). Колонка с телефоном определяется автоматически, номера приводятся к международному виду, дубли и невалидные отсеиваются. Остальные колонки становятся переменными: колонка «Город» → `{город}`.
3. **Кампания.** «Кампании» → «Создать кампанию». Напишите текст, посмотрите превью на трёх контактах, выберите базу и номера, задайте паузы и окно отправки, запустите. При запуске можно исключить тех, кому уже писали за последние N дней.
4. **Контроль.** В карточке кампании — статистика, прогресс и оценка срока. «Ответы и стоп-лист» — входящие и отписавшиеся. «Журнал» — остановки номеров и прочие события.

### Текст сообщения

- Переменные: `{name}`, `{phone}` и любая колонка базы. Регистр не важен, неизвестная переменная заменяется пустой строкой.
- Спинтакс: `{Здравствуйте|Добрый день|Приветствуем}` — в каждое сообщение попадает случайный вариант. Можно вкладывать: `{Добрый {день|вечер}|Здравствуйте}, {name}!`
- В конце добавляйте «Ответьте СТОП, чтобы отписаться».

### Как работает очередь

- У каждого номера своя случайная пауза между сообщениями (по умолчанию 25–70 с).
- Отправка идёт только в окне кампании (по умолчанию 10:00–20:00 по `TZ_NAME`).
- Дневной лимит номера растёт постепенно: `старт + шаг × число дней с первой отправки`, но не выше максимума. По умолчанию 50 → +30 в день → 500.
- Номер останавливается автоматически, а причина пишется в журнал: жёлтая карточка или блокировка WhatsApp, отказ авторизации GREEN-API (401/403), исчерпан тариф (466), 5 ошибок подряд. Включить его снова можно только вручную.
- Временные ошибки (сеть, 429, 5xx) не теряют сообщение: оно возвращается в очередь, номер ждёт минуту.
- Ответ со стоп-словом («стоп», «stop», «отписаться» — список редактируется) заносит контакт в стоп-лист и снимает его сообщения из очереди. Стоп-лист действует на все будущие кампании и импорты.

## Реалистичные сроки для 92 000 контактов

Скорость ограничивает не сервис, а WhatsApp: номер, который шлёт слишком много незнакомым людям, блокируют.

С настройками по умолчанию один номер выходит на 500 сообщений в день к 16-му дню и за первые 15 дней отправляет около 3 900 сообщений. Дальше — по 500 в день.

| Номеров | Срок на 92 000 контактов |
| --- | --- |
| 1 | ≈ 190 дней — около 6 месяцев |
| 3 | ≈ 70 дней |
| 5 | ≈ 45 дней — 1,5 месяца |
| 8 | ≈ 30 дней |
| 10 | ≈ 26 дней |

Чтобы уложиться в 1–1,5 месяца, нужно 5–10 номеров. Закладывайте запас в 2–3 номера: часть номеров на холодной базе, скорее всего, заблокируют по дороге. Оценку срока для конкретной кампании показывает её карточка.

Поднимать лимит выше 500 в день на номер не стоит: выигрыш в сроках небольшой, а риск потерять номер резко растёт.

## Как снизить риск бана

- **Используйте «живые» номера.** Номер, которым месяц-два пользовались как обычным WhatsApp (переписки, группы, аватар, имя), живёт намного дольше свежей сим-карты. Лучше WhatsApp Business с заполненным профилем компании.
- **Не ускоряйте прогрев.** Первые дни — 50 сообщений, дальше +30 в день. Новым номерам не ставьте старт выше 50.
- **Начинайте с тёплой аудитории.** Первые дни пишите тем, кто вас знает и, вероятно, ответит. Ответы — главный сигнал для WhatsApp, что вы не спамер.
- **Разнообразьте текст.** Спинтакс в приветствии, середине и концовке, обращение по имени. Одинаковый текст на тысячи номеров — самый частый повод для блокировки.
- **Избегайте ссылок в первом сообщении**, особенно сокращённых. Лучше задать вопрос и отправить ссылку тем, кто ответил.
- **Давайте способ отписаться** и не убирайте людей из стоп-листа без их просьбы. Жалоба «Спам» вредит номеру сильнее всего остального.
- **Включайте «Проверять наличие WhatsApp»** на старых базах: сообщения на несуществующие аккаунты ухудшают репутацию номера.
- **Не пишите ночью и не сужайте паузы.** Окно 10:00–20:00 и паузы 25–70 с — разумный минимум.
- **Следите за журналом.** Если номер получил жёлтую карточку, не включайте его сразу: дайте отдохнуть несколько дней и вернитесь с меньшим лимитом.
- **Пишите только тем, кто давал согласие** на сообщения от вас. Это и требование закона, и главный фактор того, как часто на вас жалуются.

Гарантии от блокировки нет: рассылка с обычных номеров WhatsApp не предусмотрена правилами мессенджера. Официальный путь без риска бана — WhatsApp Business API с согласованными шаблонами.

## Тесты

```sh
npx playwright install chromium-headless-shell   # один раз
npm test                                         # SKIP_UI=1 npm test — без браузера
```

`npm test` поднимает фейковый GREEN-API (`test/mock-green.js`, порт 4000) и сервис на временной базе (порт 3999), генерирует XLSX на 92 000 строк с номерами в смешанных форматах и проверяет: скорость импорта, отсев дублей и невалидных, CSV в Windows-1251, дневной лимит, автостоп номера (yellowCard, 401, 466, 5 ошибок подряд), стоп-лист по слову «Стоп», доведение кампании до `finished`, экспорт CSV, восстановление очереди после перезапуска. Затем проходит все вкладки админки в headless-браузере и убеждается, что в консоли нет ошибок.

Ручная проверка без реального WhatsApp: `npm run mock`, затем добавьте в админке номер с любым числовым `idInstance`, токеном `goodtoken` и `apiUrl` `http://localhost:4000`. `npm run gen` создаст файл `test-92k.xlsx` для импорта.

## Интерфейс Uved.kz

В интерфейсе два раздела:

- **WhatsApp-номера** — добавление подключения GREEN-API, авторизация по QR-коду, обновление статуса, отключение и удаление номера.
- **База для рассылки** — загрузка XLSX/CSV, результаты проверки номеров и дублей, список и удаление баз.

Главная страница открывает номера. Старые адреса разделов перенаправляются на номера. Управление кампаниями, ответы, журнал и статистика удалены из фронтенда. Серверные API и сохранённые данные не менялись; описания backend-возможностей выше относятся к API.

Название Uved.kz является брендом интерфейса; домен отдельно не подключён.

## Быстрый запуск рассылки (для клиента)

1. **Подключить номер** — «Рассылки» → шаг 1: вставить `idInstance` и `apiTokenInstance` из кабинета GREEN-API, отсканировать QR-код телефоном.
2. **Загрузить базу** — файл Excel/CSV или ссылка на Google Таблицу (в таблице должен быть открыт доступ «Все, у кого есть ссылка»; загружается лист, открытый по ссылке).
3. **Запустить** — «Новая рассылка»: выбрать базу, вставить готовый шаблон или написать текст, нажать «Запустить рассылку».

Паузы, окно отправки, дневные лимиты и выбор номеров подставляются автоматически; изменить их можно в блоке «Дополнительные настройки». Карточка рассылки сама объясняет, почему отправка сейчас не идёт (нерабочее время, исчерпан дневной лимит, номер отключён). Тексты хранятся во вкладке «Шаблоны»; любой текст из формы рассылки сохраняется туда кнопкой «Сохранить как шаблон».
